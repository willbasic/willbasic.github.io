# สุ่มเลขตามสถิติ — ชุดไฟล์สำหรับเปิดให้เพื่อนใช้ (GitHub Pages)

เว็บนี้เป็นไฟล์ static ล้วน ไม่มีเซิร์ฟเวอร์ ไม่ต้องเสียเงิน
เพื่อความบันเทิงเท่านั้น สถิติในอดีตไม่ได้เพิ่มโอกาสถูกรางวัล

## ไฟล์ในชุดนี้
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ (สุ่มเลข ตารางความถี่ รายการประวัติ) |
| `lottery_all_history.txt` | ประวัติรางวัลที่ 1 เรียงงวดใหม่สุดไว้บนสุด (471 งวด ถึง 1 ต.ค. 2569) |
| `lottery_all_prizes.csv` | (สร้างให้เองหลังรัน Actions ครั้งแรก) รางวัลที่ 1 เลขหน้า 3 ตัว เลขท้าย 3 ตัว เลขท้าย 2 ตัว ของทุกงวด เรียงใหม่สุดไว้บนสุด |
| `update.py`, `requirements.txt` | สคริปต์อัปเดตข้อมูล (Sanook + ตรวจกับ GLO) |
| `.github/workflows/update.yml` | สั่งให้ GitHub รัน `update.py` ให้เองทุกวัน 18:00 น. |
| `ตัวอย่าง_update.yml` | สำเนาของไฟล์ข้างบน (เผื่ออัปโหลดโฟลเดอร์ที่ขึ้นต้นด้วยจุดไม่ได้) |

## ขั้นตอน (ประมาณ 10 นาที)
1. สมัคร GitHub ที่ github.com (ฟรี)
2. กดปุ่ม **New repository** ตั้งชื่อเช่น `lottery` เลือก **Public** แล้วกด Create
3. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในชุดนี้ลงไป (ถ้าลากแล้วโฟลเดอร์ `.github` ไม่ขึ้น ให้ทำข้อ 4) จากนั้นกด **Commit changes**
4. ถ้าไม่มี `.github/workflows/update.yml` ใน repository: กด **Add file → Create new file** พิมพ์ชื่อไฟล์ว่า `.github/workflows/update.yml` (พิมพ์ `/` แล้วระบบจะสร้างโฟลเดอร์ให้) วางเนื้อหาจาก `ตัวอย่าง_update.yml` แล้ว Commit
5. เปิดเว็บ: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**
6. รอ 1-2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/lottery/` ส่งให้เพื่อนได้เลย

## ให้ข้อมูลอัปเดตเอง
- ไปที่แท็บ **Actions** → ถ้ามีปุ่มให้เปิดใช้งาน กดยืนยัน
- เลือก **อัปเดตข้อมูลหวยอัตโนมัติ** → **Run workflow** เพื่อลองรันครั้งแรก (ครั้งแรกอาจนาน 10-25 นาที เพราะต้องอ่านข้อมูลย้อนหลังทั้งหมดและดึงเลขหน้า/ท้าย 3 ตัวทีละงวด)
- ถ้าขึ้นเครื่องหมายถูกสีเขียว แปลว่าสำเร็จ ไฟล์ `lottery_all_history.txt` จะถูกอัปเดตเอง หลังจากนั้นระบบรันทุกวันและเก็บเฉพาะงวดใหม่
- ถ้าเป็นกากบาทสีแดง: เปิดดู log ในแท็บ Actions มักเกิดจาก Sanook ปฏิเสธเครื่องของ GitHub ให้แก้โดยรัน `python update.py` บนคอมของตัวเองหลังออกรางวัล แล้วอัปโหลด `lottery_all_history.txt` ที่ได้ทับไฟล์เดิมแทน
- GitHub อาจหยุดงานตั้งเวลาของ repository ที่ไม่มีความเคลื่อนไหวเกิน 60 วัน ถ้าเกิดขึ้นให้เข้าแท็บ Actions แล้วกดเปิดใหม่

## ข้อควรระวัง
- repository แบบ Public ทุกคนเปิดดูไฟล์ได้ อย่าใส่รหัสผ่านหรือข้อมูลส่วนตัว
- ข้อมูลจาก GLO อยู่ภายใต้สัญญาอนุญาต Creative Commons ที่ไม่อนุญาตให้ใช้เชิงพาณิชย์ ถ้าจะใส่โฆษณาหรือหารายได้ ควรตรวจเงื่อนไขของ GLO และ Sanook ก่อน
- เงื่อนไขและโควตาฟรีของ GitHub อาจเปลี่ยน ควรเช็กที่หน้าของ GitHub อีกครั้ง

## อัปเดตจากเวอร์ชันก่อนหน้า (ถ้าเคยตั้งไว้แล้ว)
เวอร์ชันนี้เพิ่มการสุ่มและเก็บข้อมูลเลขหน้า 3 ตัว เลขท้าย 3 ตัว และเลขท้าย 2 ตัว ให้ทำดังนี้
1. อัปโหลดไฟล์ `index.html` และ `update.py` ใหม่ทับของเดิม (Add file → Upload files)
2. เปิดไฟล์ `.github/workflows/update.yml` ใน repository กดรูปดินสอ แล้วแทนที่เนื้อหาด้วยจาก `ตัวอย่าง_update.yml` จากนั้น Commit
3. แท็บ Actions → เลือก **อัปเดตข้อมูลหวยอัตโนมัติ** → **Run workflow** รอจนขึ้นเครื่องหมายถูก แล้วจะมีไฟล์ `lottery_all_prizes.csv` เพิ่มขึ้นใน repository
4. ระหว่างที่ยังไม่มีไฟล์ `lottery_all_prizes.csv` หน้าเว็บยังสุ่มได้ แต่เลขหน้า/ท้าย 3 ตัวจะสุ่มเท่ากันทุกตัว (ยังไม่อ้างอิงจากสถิติ)
5. ถ้า Actions ขึ้นสำเร็จแต่ไม่มี `lottery_all_prizes.csv` ให้เปิดไฟล์ `lottery_prize_debug.txt` (ถ้ามี) หรือ log ของ Actions แล้วส่งให้ผู้พัฒนาดู มักเกิดจากหน้า Sanook เปลี่ยนรูปแบบหรือไม่ให้เครื่องของ GitHub เข้า
